3. Export for GitHub Pages

Output includes scroll mode (default), optional presentation mode, six reading-overlay colours, overlay strength control, original PDF download, and working GIFs when present. Slide transitions and click-to-reveal animations are intentionally not converted.

Uses PDF.js and JSZip. For reliable conversion, publish this entire folder on GitHub Pages and open it over HTTPS, rather than opening index.html directly as a local file. PDF.js is loaded from a public CDN, so an internet connection is required while converting.
